# World Action Model 设计（v3：域对抗 JEPA）

> 设计演变：
> - **v1 深度重建**（2026-09-08 废弃）：复原网络从隐编码重建深度图、转点云与 GT 比较。核查数据后发现 DROID 真机侧无深度传感器（无 GT 可比），仿真侧 stack 族主力子集（stack-platforms 17.6k + stack-wide 10.2k，约 80%）也无深度。伪深度（DepthAnything）是备选但未采用。
> - **v2 点轨迹预测**（2026-09-08 废弃）：CoTracker3 离线生成伪标签。评审指出跟踪撒点密度与存活率本身与纹理/画风耦合，伪标签带域偏。
> - **v3 域对抗 JEPA**（当前）：不解码任何信号，隐空间内预测下一帧编码，画风无关性由域对抗约束逼出，无需任何伪标签。

## 1. 目标与动机

- 用仿真数据（PhysicalAI-SingleArm，~38k 集）填充真机数据（DROID 同任务子集，~7.5k 集）的体量，训练一个**画风无关**的世界动作模型，避免每次迭代都真机采集。
- 任务族对齐：drawer / cabinet / stack 三族（仿真 6 个子数据集与 DROID 关键词子集一一对应，见 [data_preparation.md](data_preparation.md)）。
- 隐空间中"仿真开抽屉"与"真机开抽屉"应落在同一区域，且时序动态共享同一套规律。

## 2. 总体架构

```
                    ┌─────────────────────────────────────────┐
x_t (RGB) ──► VLM中间层 ──► token ─┐                          │
文本(指令/模板) ───────────────► cross-attn ──► z_t ──┐        │
                                    在线编码器 E       │        │
                                                     ▼        │
                            时序预测器 P: (z_t, a_t, query) ──► ẑ_{t+1}
                                                     │        │
x_{t+1} ──► Ē (E 的 EMA 拷贝, stop-grad) ──► z*_{t+1} ◄────────┘  L_jepa

z_t / ẑ_{t+1} ──► [GRL 梯度反转层] ──► 域判别器 D ──► sim/real 二分类  L_dom
```

三个组件：

| 组件 | 说明 |
|---|---|
| 在线编码器 E | 冻结的开源 VLM（SigLIP / Qwen2-VL）取中间层 token，与文本 token 做 cross-attention → z_t。仿真侧文本由任务目录名模板生成（"open the left cabinet door"），见 [data_preparation.md](data_preparation.md) |
| 时序预测器 P | 小 transformer/GRU：`(z_t, a_t, learned query) → ẑ_{t+1}`。动作 a_t 必须先经 `action_align.py` 统一为 7-DoF 末端增量 + 夹爪 |
| 目标编码器 Ē | E 的 EMA 滑动平均，只前向不反传，产生预测目标 `z*_{t+1}`（JEPA 标准做法） |
| 域判别器 D | 浅层 MLP（2~3 层，必要时 spectral norm），经 GRL 挂在 z_t 与 ẑ_{t+1} 上 |

## 3. 损失函数

```
min_{E,P}  max_D   L = L_jepa + L_var − λ · L_dom

L_jepa = ‖ ẑ_{t+1} − stop_grad(Ē(x_{t+1})) ‖²        # 隐空间时序预测，两域混训
L_dom  = 域判别器交叉熵（D 挂 GRL，E 端梯度取反）        # 逼 E 抹掉域可分信息
L_var  = VICReg 式方差正则（z 各维方差 ≥ 阈值）          # 防塌缩保险
```

- **GRL**：前向恒等，反向梯度 ×(−λ)。λ 用 DANN 渐进日程：训练初期 ≈0，按 `2/(1+exp(−10·p))−1`（p 为训练进度）缓慢升至目标值。
- **塌缩风险**：E 把所有输入映成一点可同时骗过 L_jepa 和 D。防线 = EMA 目标编码器 + 预测器只在在线侧 + L_var 方差正则，三者缺一不可。
- **任务信息误伤**：若某任务族高度集中于单一域（当前 stack 族 ~80% 在仿真侧），"这是 stack"本身泄露域信息，对抗会误删任务信息。缓解：先靠 λ 渐进日程观察；必要时升级 **CDAN**——判别器以任务族为条件，只惩罚与任务无关的域信息。
- **batch 配比**：仿真/真机各半，域损失才稳定。

## 4. 阶段二：特权信息蒸馏（sim→real 的关键收益）

预训练完成后，利用"仿真环境里一切可知"的事实做特权信息微调：

1. **仿真侧提取特权信息**：物体 6D 位姿、抽屉位移量、柜门开合角、夹爪接触力、与目标物距离等——Isaac Sim 直接可读，精确无噪。
2. **挂特权预测头**：`(z_t 或 ẑ_{t+1}) → 特权信息`，只在有标签的仿真集上监督。
3. **域对抗保持开启**：隐空间两域对齐 ⇒ 仿真上学的特权头可直接用于真机片段推理——真机上**没有传感器也能"读出"**柜门开了多少度、方块是否被抓稳。
4. 这等价于把特权蒸馏（privileged distillation）从策略学习搬到世界模型：仿真提供全知监督，域对抗负责迁移。

## 5. 验收指标

| 探针/指标 | 目标 | 验证什么 |
|---|---|---|
| 域探针（冻结 z 线性分 sim/real） | ~50%（瞎猜） | 域信息已抹除 ✅ |
| 任务探针（冻结 z 线性预测 action/任务族） | 高；线性探测 R² ≥ 0.5（[architecture.md](architecture.md)） | 任务信息没误删 ✅ |
| t-SNE 肉眼检查 | 同任务族两域混聚，不同族分开 | 隐空间语义结构 |
| 跨域配对匹配率（[architecture.md](architecture.md) 主实验） | 显著高于随机基线 | 画风无关性成立 |
| 特权头真机推理抽检 | 与人工目测一致（如柜门开合角趋势） | 阶段二迁移有效 |

## 7. 主要风险

| 风险 | 缓解 |
|---|---|
| 塌缩（E 退化） | EMA + 预测器不对称 + L_var；域探针/任务探针早期监控 |
| λ 过强误删任务信息 | 渐进日程；CDAN 条件化；任务探针监控 |
| 判别器过强训练震荡 | 浅层 MLP + spectral norm；batch 两域各半 |
| 两域物理/视角差异远超画风差异（视角本身是域信息） | 一期先接受；二期可选视角相近片段子集降低难度 |
