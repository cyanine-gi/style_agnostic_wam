# Stage 2 域对抗训练失败台账

记录 Stage 2（消灭 reg_agnostic 域信息）三次训练的失败形态、证据与机制诊断。
终审口径一律为**离线探针**（冻结末态 E → 逐域采样各 1500 帧 → train 流训
线性探针 → val 流评估）；train/val 在线读数只作辅助。三次运行输出
（2026-09-17 用 ckpt args 与 log 键名核实）：**run1 = outputs/stage2_bak**
（λ 末值 0.1、无 disc/inner/disc/e 键）；**run2 = outputs/stage2_bak2**
（λ 末值 0.03、有 disc/inner；其 log.jsonl 尾部混入一条 run3 step-0
记录——run3 首次启动时 run2 目录尚未挪走所致，随后用户挪走并重跑）；
**run3 = outputs/stage2**（纯净，20K 步 2.02h）。

## 共同背景

- 目标：reg_agnostic 通道域探针准确率 ≈ **经验域先验基线**（多数类比率，
  实测统计，不假设 0.5——数据集自然比率 real:sim ≈ 52031:21249 ≈ 71:29；
  在 50/50 均衡采样口径下该基线才是 50%±5），深度指标退化 ≤5%。
- 三次初始化相同：E ← stage0@99999，T/adapter/D/signals ← stage1@149999。
- 三次离线探针终审结果全部 **reg_agnostic ≈ 1.000（run3 为 0.999）**——
  域信息始终线性可读，三次均未过验收门。

## run1（2026-09-16）：判别器追不上 E

- 配置：λ 0→0.1 / ramp 5k；判别器 lr 1e-4、每步单次更新（与 E 同步）；
  无内循环。
- 症状：`train/disc/acc_e` 从 7k 起钉 0.5；val 在线探针 1.0↔0.0 剧烈振荡
  （15k 处 0.000 = 探针边界被整体甩反）；anchor 0.176→~0.4；joint_pos
  退化 ~13×。
- 机制：E 在较强 GRL 梯度下快速搅动特征骗"当前"判别器，判别器追不上
  移动目标——acc 0.5 是"追不上"而非"特征干净"，新探针立刻找到边界。
- 教训：**train acc=0.5 单独不能作成功证据**；验收必须离线重训探针。

## run2（2026-09-17）：判别器碾压 → 梯度死亡

- 配置：λ 0→0.03 / ramp 10k；判别器 lr 3e-4 + 内循环 4 次/步
  （detach 特征）；仍 GRL 梯度反转 + BCE。
- 症状：`disc/acc_e` **step 10 即 1.0** 且全程保持（1727/2000 点 >0.99）；
  `grl/e` ≈ 2e-5；val 探针全程 1.000 不再振荡（E 不再被鞭打，恰证明
  对抗梯度消失）；anchor 0.176→0.40；joint_pos 退化 ~13×。
- 机制：判别器自信正确 ⇒ BCE 处于 sigmoid 饱和区 ⇒ 经 GRL 回传的
  对抗梯度 ≈ 0，λ 大小无关紧要。E 从未受到清洗压力。
- 教训：饱和型 minimax（梯度反转 + BCE）在判别器占优时梯度消失，
  与 GAN 的饱和失败同族。

## run3（2026-09-17）：non-saturating 标签翻转 →  overshoot 振荡

- 配置：同 run2，但 E/T 侧改 non-saturating（判别器参数冻结图上的
  标签翻转 BCE）；判别器训练收进内循环（唯一通路）。
- 症状：`disc/acc_e` 全程 0↔1 大幅振荡（均值 0.53，p5=0.00，p95=1.00，
  末段 acc=0.000 = 判别器被推到自信判反）；`disc/inner` 全程不收敛
  （均值 3.55，p95 6.98）；val 在线探针 0.1↔0.95 反复振荡，终点 0.744；
  anchor 0.176→0.42~0.53（三次中最重）；joint_pos 仍退化。
- 机制：标签翻转 BCE 的最优点是"判别器自信判**错**"，不存在稳定
  不动点——E 把特征推过边界 → 判别器内循环重学反向边界 → E 再反向
  overshoot，形成振荡环。对抗梯度确实活了（对比 run2），但目标是错的。
- 教训：non-saturating 解决"梯度死"，不解决"目标错"；对抗目标
  本身应指向混淆态（p=0.5）而非判错态。

## 三次共同观察

1. **对抗动力学三连败的三个模式**：追不上（弱判）→ 饱和死（强判）→
   overshoot 振荡（非饱和翻转）。判别器强度的甜蜜点极窄且随训练漂移，
   纯对抗路线调参成本高。
2. **anchor 漂移与对抗无关**：三次都从 0.176 漂到 0.4+（run2 几乎无
   对抗梯度也照漂）——联合微调固有梯度（depth/dyn/signal 进 E，
   lr 5e-5）所致，锚权重 0.1 压不住。**独立问题，未处理，待裁决。**
3. **结构性拔河（假设，待验证）**：joint_pos 信号头按设计只读
   reg_agnostic，而关节分布本身跨域不同（real/sim 轨迹分布差异）——
   信号监督持续往 agnostic 槽位注入域相关信息，对抗/惩罚每清一次它
   就注一次。任何清洗方案都要面对这个再注入源。
4. **深度与动力学三次均完好**：val/depth/true 退化 <1%，latent_mse
   step_4 0.030→0.025 左右——清洗从未伤及主任务，代价集中在
   joint_pos 信号与 anchor 漂移。

## 2026-09-17 裁决·三（定稿方案，用户已确认，待实施）

两个清洗目标**都实现、独立开关**，可同时开也可单开；配置在
`configs/model.yaml` 的 `stage2.adv` 节：

```yaml
stage2:
  adv:
    hsic:    { enabled: true,  weight: 1.0,  ramp_steps: 10000,
               buffer_size: 256 }  # 默认开；跨步累积缓冲
    entropy: { enabled: false, weight: 0.03, ramp_steps: 10000 }  # 默认关
```

### HSIC 惩罚（默认开）

- 双挂点与对抗一致：E 侧 clip 全部帧的 reg_agnostic（B×L=48 样本，每个
  样本 = 2×384 拉平成 768 维向量）+ T 侧每展开步的 r̂[:, agnostic]。
- **跨步累积样本（用户裁决，硬性要求）**：每个挂点维护一个 FIFO 缓冲
  （容量 ~256 样本），核矩阵用「当前 batch（带梯度）+ 缓冲（detach）」
  拼接计算——单 batch 48/32 样本的 HSIC 估计噪声太大；梯度只经当前
  batch 样本回传，缓冲只作统计基底。
- 有偏 HSIC 估计：中心化核 `trace(KHLH)/n²`，特征用 RBF 核（带宽 =
  成对距离中位数，median heuristic），域标签用二值核；报归一化值
  （除以 √(HSIC(x,x)·HSIC(y,y))）便于跨步比较。
- 梯度直接进 E/T（无判别器、无对弈动力学）；λ 按 ramp_steps 从 0 爬升。
- 监控量：`train/hsic/e`、`train/hsic/t`、`train/hsic/lambda`。

### 熵最大化混淆（默认关）

- E/T 侧目标 = 把判别器后验推向**批次经验域先验 π̂**（用户裁决：
  不写死 p=0.5，数据集并不完美均衡）：逐样本软标签交叉熵
  `−[π̂·log p + (1−π̂)·log(1−p)]`，π̂ = 当次 batch 域标签均值（常数，
  无梯度）。最优点 p=π̂ = 混淆态，稳定不动点；在 50/50 均衡 batch 下
  π̂=0.5，退化为标准熵最大化。替代 run3 的标签翻转 BCE。
- 仍走判别器参数冻结图（梯度只进 E/T），判别器训练照旧收在
  `disc_inner_loop`（detach 特征，唯一通路）。
- 监控量沿用 `train/grl/e`、`train/grl/t`、`train/disc/*`。
- 熵对抗关闭时判别器/内循环不建不跑（省算力）。

### val 探针独立训练（验收口径修正）

- validate() **不再借用** train 阶段的在线 `DomainProbe`（run1/run3 的
  在线探针振荡证明它会滞后/翻转，读数不可信）。
- 新流程：val 前向收集冻结特征（patch mean-pool / reg_domain /
  reg_agnostic 三通道）+ 域标签 → 每次 val 现场**从零训练一个线性探针**
  （收集到的 val 特征随机 50/50 分训练/评估两半，logistic 回归 500 步
  Adam lr 1e-2，与离线终审同配方）→ 报 `val/probe_e/*`。
- 收集时**按域分层**（两域各取固定批数，不允许 val_loader 顺序导致的
  单域批次）；**验收基线不假设 0.5**：同报 `val/probe_prior` = 当次
  收集样本的经验多数类比率，判据 = probe acc 与先验基线之差 ≈ 0。
- train 阶段的在线探针保留但只作 `train/probe/*` 参考读数，不再进 val。
- **λ_hsic = 1.0**（2026-09-17 冒烟实测定值）：init 处 nHSIC ≈ 0.92~0.96
  （强依赖，与探针 1.000 一致）；梯度 RMS ≈ 4.5e-6/dim，已是 joint_pos
  再注入梯度（1.8e-7/dim）的 ~25 倍——agnostic 列上 HSIC 是唯一够分量的
  清洗力；nHSIC 有界 ≤1，清洗干净后贡献自动退零。若中期探针读数不动，
  下一步再抬 λ。
- 单 batch（n=48）nHSIC 实测 0.000——估计退化，跨步缓冲确为硬性要求
  （batch48+buf256 → 0.923，与大样本一致）。
